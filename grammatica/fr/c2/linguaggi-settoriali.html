Les langues de spécialité

par Alessio · professeur d'italien langue étrangère, master ITALS

Chaque monde italien a son code : l'université écrit "il presente contributo si propone di", le médecin "assumere a digiuno", le guichet "munirsi di documento". Le vrai C2 n'est pas parler difficile : c'est reconnaître les codes et passer de l'un à l'autre sans friction.

Trois codes côte à côte

CodeTraitsExemple
accademicoimpersonale, nominale, cautoi dati suggeriscono che il fenomeno sia più complesso
burocraticoformule fisse, passivil'istanza va presentata entro i termini di cui all'art. 3
medicotecnicismi + istruzioniposologia: una compressa die, lontano dai pasti
giornalisticonominale, citazioni, presentesvolta all'ateneo: "più fondi alla ricerca"
L'italien académique aime la prudence : sembra suggerire, si potrebbe ipotizzare, non è da escludere. Ce n'est pas de l'incertitude : c'est l'étiquette de la recherche. Le changement de code (expliquer "una compressa die" à sa grand-mère) est l'exercice C2 par excellence.

Traduire entre codes

SpécialiséItalien courant
il candidato è pregato di munirsi di valido documentoporta con te la carta d'identità
assumere il farmaco a digiunoprendi la medicina a stomaco vuoto
il presente lavoro intende indagarein questa tesi studio

Les erreurs les plus fréquentes

  • in questa tesi io penso che → il presente lavoro intende mostrare che (les essais évitent le io direct)
  • prenda la pastiglia quando vuole → assumere una compressa al giorno, lontano dai pasti (la notice est précise)
  • i dati dimostrano sicuramente al cento per cento → i dati suggeriscono / indicano (prudence académique)

Essayez tout de suite

Reconnaissez et changez de code :

  1. Nel saggio: "i risultati una correlazione."
  2. Sul foglietto: " una compressa al giorno."
  3. All'anagrafe: " documento in corso di validità."
  4. Alla nonna: " a stomaco vuoto."
  5. In un articolo scientifico: " un secondo fattore."
